# 빈틈 (BEENTEUM)

목적에 맞는 카페를 탐색하고 혼잡도와 공간 정보를 확인할 수 있는 카페 탐색 서비스입니다.

## 프로젝트 소개

빈틈은 카페 방문 전에 사용자의 방문 목적과 조건에 맞는 카페를 탐색하고,
카페의 공간 정보와 혼잡도 정보를 확인할 수 있도록 돕는 서비스입니다.

## 주요 기능

- 위치 및 지역 설정
- 주변 카페 탐색
- 방문 목적 선택
  - 공부
  - 업무
  - 대화
  - 휴식
- 목적 및 조건 기반 카페 추천
- 카페 상세 정보 확인
- 혼잡도 확인
- 카페 비교
- 즐겨찾기
- QR 기반 현장 혼잡도 제보
- 관리자 카페/공간 정보 관리
- 관리자 사용자 제보 관리

## 기술 스택

- React
- Vite
- JavaScript
- CSS
